# Monitor-IA

## Requisitos

- [Node.js y npm](https://nodejs.org/)  

---

## Clonar el proyecto

```bash
git clone https://github.com/mhenaoe/Monitor-IA.git
cd Monitor-IA
```

---


## Para Configurar Node / Next.js

1. Instalar dependencias:

```bash
npm install
```

2. Ejecutar aplicación en modo desarrollo:

```bash
npm run dev
```

3. Abrir en navegador:

```text
http://localhost:3000
```
